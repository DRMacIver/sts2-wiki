# STS2 Wiki

Static Astro site generated from decompiled Slay the Spire 2 game data.

## DOTNET_ROOT

The `ilspycmd` tool requires `DOTNET_ROOT` to point to the dotnet libexec directory, NOT the bin directory. `just decompile` auto-detects it (`$(dirname $(dirname $(readlink -f $(which dotnet))))/libexec`); export `DOTNET_ROOT` yourself only if that fails:

```bash
export DOTNET_ROOT=/opt/homebrew/Cellar/dotnet/<version>/libexec  # check ls /opt/homebrew/Cellar/dotnet/
```

## Versions

The version list is single-sourced from the `data/vX.Y.Z/` directories via `scripts/versions.py`. The justfile's default `version`, `build-all-versions`, and the site's fallback (`site/src/versions.json`, regenerated by `just update-versions`) all derive from it. Adding a new patch requires no manual version edits — only a patch-notes page.

## Commands

Scripts run as modules: `uv run python -m scripts.extract_cards` (not `python scripts/extract_cards.py`).

Justfile orchestrates everything:
- `just detect-version` — show installed game version
- `STS2_VERSION=$(just detect-version) just new-patch` — full automatable pipeline for a new game version (decompile, extract, llm-extract, images, generate, build); prints the remaining manual steps
- `just diff-latest` — diff the two most recent versions' data (includes per-entity events)
- `just decompile` / `just extract-pck` / `just extract` / `just extract-images` — individual pipeline steps
- `just llm-extract` — LLM-based per-entity extraction (cached, incremental)
- `just generate` — generate site content from extracted data
- `just build-site` — build Astro site
- `just check` — ruff + mypy + pytest + data consistency + links + images (must pass before committing)

## Quality

- `just check` must pass before committing
- Tests live in `tests/` (pytest); add a regression test when fixing an extraction/generation bug
- `scripts/check_consistency.py` validates the latest version's data (cross-refs, tag balance, coverage); structural problems are errors, known game-data limitations are warnings
- Don't commit `decompiled/`, `extracted/`, or scratch files
- Data files in `data/` are committed per version
- `site/public/images/` is committed (CI has no game install); `scripts/extract_images.py` only rewrites images whose *visible* pixels changed, so re-runs are git-noise-free
